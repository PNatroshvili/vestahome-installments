# vestahome.ge — განვადების ინტეგრაცია (BOG + Credo)

ეს პროექტი აკავშირებს **vestahome.ge**-ს (Shopify, Basic გეგმა) **საქართველოს ბანკის**
და **კრედო ბანკის** ონლაინ განვადების სისტემებთან.

## რატომაა ეს ცალკე "middleware"

Shopify Basic-ზე ნატიურ checkout-ში საკუთარი გადახდის მეთოდის ჩამატება
ტექნიკურად შეუძლებელია (ეს Shopify Plus-ის ფუნქციაა). ამიტომ ეს გამოსავალი
checkout-ს გვერდს უვლის:

```
პროდუქტის გვერდი (Shopify, Dawn თემა)
   -> "განვადება" ღილაკი
   -> ეს backend: ქმნის Shopify Draft Order-ს (გადაუხდელი) + ბანკის შეკვეთას
   -> მომხმარებელი ბანკის გვერდზე ირჩევს განვადების პირობებს და ადასტურებს
   -> ბანკი გვიდასტურებს (BOG: webhook; Credo: პერიოდული შემოწმება)
   -> ეს backend Draft Order-ს გარდაქმნის ნამდვილ, "გადახდილ" Shopify შეკვეთად
```

## სტრუქტურა

- `src/` — Node.js/Express backend (deploy-ვდება ცალკე, Shopify-სგან დამოუკიდებლად)
- `theme/` — ფაილები, რომლებიც უნდა ჩასვათ Shopify-ს თემაში (Dawn)
- `docs/SETUP-ka.md` — ნაბიჯ-ნაბიჯ ინსტრუქცია (**აქედან დაიწყეთ**)

## სწრაფი დაწყება (ტექნიკური მიმოხილვა)

```bash
cp .env.example .env
# შეავსეთ .env — იხ. docs/SETUP-ka.md
npm install
npm start
```

დეტალური, არა-ტექნიკური ინსტრუქციისთვის იხილეთ [docs/SETUP-ka.md](docs/SETUP-ka.md).
